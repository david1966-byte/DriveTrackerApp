# Drive Tracker App

אפליקציית אנדרואיד מודרנית למעקב נסיעה וחנייה.

## תכונות עיקריות
- מעקב מצבים (כבוי / בנסיעה / בחנייה) עם שינויי צבע דינמיים.
- חיווי קולי (TTS) בעברית בהתחלפות כל מצב.
- התראה קבועה בווילון ההתראות המציגה את המצב העדכני.
- כפתור פתיחת מיקום חנייה ב-Google Maps.
- כפתור פתיחת אפליקציית Pango (או מעבר לחנות).
- תמיכה מלאה ב-CI/CD ובנייה אוטומטית דרך GitHub Actions.
